# XiaoGou Servers Eyes — 产品级 UI 设计说明（遵循 UI_DESIGN_GUIDELINES.md §18）

- **产品名称**：小狗服务器
- **产品类型**：多服务器实时监控与轻量运维 Android App
- **目标用户**：同时管理多台 Linux VPS / 自建主机 / 容器节点的开发者与运维人员
- **核心使用场景**：多机实时状态巡检、单机性能瓶颈排查、Docker/Systemd 服务状态确认与日志查看、阈值告警提醒
- **支持主题**：浅色 / 深色 / 跟随系统（全套语义 Token 映射，非简单反色）
- **目标设备**：Android 手机（竖屏/横屏）、折叠屏与平板（Adaptive NavigationRail + 双栏分屏）
- **技术栈**：Kotlin + Jetpack Compose + Material 3（Strict `dp` / `sp`、Edge-to-Edge WindowInsets、48dp 最小触控区域、TalkBack 语义标签）

## 三套备选视觉方向

| 方案 | 风格定位 | 品牌主色（浅/深） | 看板信息密度 | 适用偏好 |
|---|---|---|---|---|
| **方案 A · Ops Precision** | 冷静专业运维台 | `#2563EB` / `#5B93FF` | 中高（双列卡片 + 实时折线微图 + 集群脉冲条） | 兼顾多机扫视与曲线趋势 |
| **方案 B · Material 3 Bento** | 现代极简工具风（贴近规范 §4.2） | `#315EFB` / `#7894FF` | 舒朗（Bento 摘要卡 + 异常焦点置顶展开） | 看重呼吸感与原生 Material 质感 |
| **方案 C · Matrix Telemetry** | 高密度终端矩阵 | `#0D9488` / `#2DD4BF` | 高（等宽数字 + 单屏 6~10 台紧凑状态矩阵） | 节点较多、偏好等宽数据流 |

> **门禁说明**：已选定 **方案 A · Ops Precision** 作为正式视觉系统。v1.1、v1.2 与 v1.3 新增界面同样先更新方案 A 交互原型并待用户确认后再开展 UI 编码。
> - **v1.1 已确认落地**：多机搜索置顶、Swap/网络/Load 曲线、容器启停、单机告警覆盖、配置加密备份及输入法贴合布局。
> - **v1.2 已确认落地**：详情页 CPU 温度/磁盘 IO/Inode/进程详情、告警中心独立阈值与已恢复筛选状态、设置页夜间免打扰（DND）与文件级（SAF）备份预览及合并/替换策略。
> - **v1.3 已确认落地**：看板多维排序与批量管理、编辑页跳板机（ProxyJump）与 SAF 私钥文件导入及超时设置、详情页容器实时 CPU/Mem 占用与搜索过滤、诊断历史命令回溯与输出一键复制、设置页后台巡检周期调整。
> - **v1.4 待确认增量原型**（`docs/prototypes/v1.4_detail_trend.html`）：详情页 KPI 速览、可切换指标的趋势卡（真实时间轴 / Y 轴刻度 / 告警阈值线 / 拖动读数 / 实时增量）、Header 刷新与暂停采集、近期告警时间线、Top 进程排序。

## 详情页趋势卡设计约定（v1.4）

- **信息层级**：KPI 速览 → 趋势卡 → 告警时间线 → Top 进程，单页只保留一个图表焦点，不再并列多张折线卡。
- **指标切换**：CPU·内存 / 磁盘 / 温度 / 磁盘 I/O / 网络 / Load 六个 chip，同一张卡内切换，避免卡片堆叠。
- **时间轴**：X 轴按真实时间比例绘制；≤6h 显示 `HH:mm`，更长窗口显示 `MM-dd HH:mm`；Y 轴 4 档刻度带单位。
- **阈值表达**：告警阈值以虚线 + 文字标签（如「警告 80%」）呈现，颜色仅作辅助，满足规范 §4.3 / §11。
- **交互**：横向拖动显示十字准线与读数气泡，松手 1.5 秒淡出；「实时」开关开启时增量追加并自动左移。
- **状态**：首次加载骨架屏；刷新保留旧曲线；无历史数据说明原因并提供「立即刷新」；失败提供重试且不暴露原始异常（规范 §13）。
- **性能**：本地历史按窗口分桶聚合（15m→10s、1h→30s、6h→2m、24h→5m、48h→10m），单序列上限约 400 点；不使用第三方图表库（规范 §16.6）。
- **无障碍**：图表提供动态朗读摘要（指标、区间、峰值、均值）；图例同时使用颜色、线型与文字；触控目标 ≥48dp。
